# calisthenics-home-legal

Static privacy policy, terms of use, and account-deletion pages for the Android app **calisthenics-home** (קליסטניקס מהבית), a Hebrew home calisthenics program for beginners.

Hebrew (right to left) is the default. English is under `/en/`. The pages are static HTML: no JavaScript, no trackers, and no external fonts. This repository does not contain the app, user data, or secrets.

Effective date of the documents: November 21, 2026.
